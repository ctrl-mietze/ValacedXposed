# @vexcord/types

Local, versioned SDK declarations. Install from this checkout using a local file dependency or copy the declaration files into your plugin project. This package is not published to npm.

The definitions match Vexcord SDK v1. Existing Valenced types may be used alongside them. See the [API reference](../docs/SDK.md).

The `example/` directory demonstrates a format-1 plugin bundle. It is not included in the default installed plugin list.
