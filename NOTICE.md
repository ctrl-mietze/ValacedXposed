# Credits & project provenance

**Vexcord** is maintained by ctrl-mietze / Veyra, continuing the ValacedXposed project. The Git history includes the original Valenced development and subsequent modifications. The standalone repository was initialized from ValacedXposed commit `b4eceb52a8e3a77299e16555b79ecefab7dfb57d` (1.0.26).

- **Valenced:** [Valenced/valenced](https://github.com/Valenced/valenced), original Kotlin/Xposed, Hermes and plugin framework, GNU GPL v3. Original author/contributor notices, Git history and licenses are retained.
- **Vencord:** [Vendicated/Vencord](https://github.com/Vendicated/Vencord), GNU GPL v3 or later, source inventory and supported pattern-derived mobile ports. The compiler records the precise source revision, original files and contributors. It does not redistribute original desktop bundles.
- **Mobile equivalents:** independent community authors, with source and contributor metadata retained in manifests and the artifact lock.
- **Additional libraries:** retain their own license files and notices, including `bundle/LICENSE` and `bundle/lib/patcher/LICENSE`.

Vexcord's own contributions include the native manager, connection management, plugin analysis, mobile compiler, motion theme studio, additive Vexcord SDK and new project identity. This is an independent distribution of derived open-source software, not a claim of sole authorship or a clean-room implementation.

Discord and other project names belong to their respective owners.
