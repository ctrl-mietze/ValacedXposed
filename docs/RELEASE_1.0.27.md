# Vexcord 1.0.27

The first independently hosted Vexcord release, based on ValancedX 1.0.26.

- New product name, icon, GitHub repository and README.
- Vexcord SDK v1: lifecycle-scoped module discovery, reversible hooks, Flux observation, per-plugin storage, message send/edit transforms, native runtime info.
- Original Valenced APIs, plugin IDs, sources, importer, compiler catalog, theme engine and data paths kept.
- 57 Vencord mappings / 56 distinct mobile targets; 21 generated ports, 5 integrated ports and 31 Android-equivalent mappings. No blanket activation.
- All ten source presets in Repository Hub; existing enabled states stay unchanged.
- Production package `ctrl.mietze.valacedxposed` and original signing key maintained.

Install over ValancedX rather than uninstalling it. Restart Discord afterwards. See [installation](INSTALL.md), [SDK](SDK.md) and [credits](../NOTICE.md).

This is an additive rebrand and API update, not a replacement of the existing core. Runtime binding and actual feature behavior remain separate verification stages.
