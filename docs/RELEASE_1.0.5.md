# ValancedX 1.0.5 — Native Plugin Manager

- New Plugins tab: installed plugins, searchable discovery, sources, installation plans, enable/disable and uninstall.
- Reuses the existing Valenced resolver, artifact verification and native plugin lifecycle; user confirmation required for installs.
- Official Valenced Community and optional dxckie-cell index; custom HTTPS sources. Archived Revenge Next linked for reference, not advertised as universally compatible.
- Bounded authenticated manager-to-Discord request mailbox. No root filesystem copying or arbitrary command execution.
- Changes may require a Discord restart. Discord and application signing remain unchanged.
