These are independent community repositories, not Vexcord-owned packages. Existing installations retain their live catalogs. Fresh installs can add the presets through Sources. Counts can change when upstream indexes change. The previous device snapshot contained 154 source entries across these ten repositories.

Vencord equivalents use [pinned public artifacts](../tools/vencord-compiler/mobile-lock.json). Multiple providers for the same plugin ID remain individually selectable.
