# Vexcord 1.0.28 — Classic Motion

The original large translucent moving light circles are back, based on the exact ValancedX 1.0.18 implementation.

- Original two 380dp orbs and 12.4-second sinusoidal animation cycle restored.
- All 13 motion presets receive the geometric layer, alongside the existing base and ambient gradient layers.
- Aurora, Bloom and Eclipse retain their original classic colors; newer themes use their own glow colors.
- The manager preview mirrors the effect.
- Existing background assets and theme selection remain compatible, including v1/v2/v3 assets. No theme reapplication is required.
- Foreground content and touch controls are unchanged. Loops stop in the background and respect reduced motion.
- Vexcord SDK, plugins, source records, package identity and signing continuity are unchanged.
