# ValancedX 1.0.18 — Revenge Compatibility

- Opt-in master mode, separately enabled plugins, dependency cascade on disabling. Old JS imports from earlier releases are also gated.
- Six built-in reimplementations: Show Image Links, Pastelize, Always Animate (existing animated assets only), No Typing, Char Counter, Clean URLs (outgoing/copy).
- Expanded original JS catalog: nine Nexpid and three redstonekasi manifest links verified reachable. Legacy imports remain experimental, hash-checked when upstream provides a SHA-256, never auto-enabled.
- Legacy Metro namespace lookup and patch receiver compatibility improved. Native Revenge Next JAR/ZIP plugins are not imported by this adapter.
- Built-in ports include credits; equivalent active Valenced plugins are not enabled simultaneously through the manager.
- Same package, release signature, themes and settings.

## Attribution and scope

Independent ports of legacy features inspired by Cynosphere's ShowImageLinks, Pastelize and AlwaysAnimate (source mirror https://github.com/skullbite/VendettaPlugins, public-domain Unlicense); redstonekasi's No Typing (BSD-3-Clause https://github.com/redstonekasi/vendetta-plugins); and nexpid's Char Counter and Clean URLs (CC-BY-4.0 https://github.com/nexpid/RevengePlugins). The native hooks are adapted to Valenced's current APIs; not a complete copy of the original plugins or their settings. Some features overlap existing Valenced community plugins.
