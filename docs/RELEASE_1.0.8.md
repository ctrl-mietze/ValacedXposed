# ValancedX 1.0.8 — Discord Themes and Legacy compatibility

- Standalone Themes bottom navigation with Discord and Manager subpages.
- Bridge to the existing Valenced Themes API and settings plugin; install/update the real theme engine, list registered themes/packs, select or reset color/font/icon/emoji packs.
- Spec-2 legacy color and background JSON import, persistent registration, six verified Catppuccin/system24 theme links. Theme plugins discoverable from enabled repositories.
- Additional ndb1995 Valenced repository recommendation. Legacy catalog and URL importer for old Revenge/Vendetta JS bundles, preview metadata and downloaded SHA-256, install disabled using native validated ZIP staging.
- Experimental adapter for legacy lifecycle, module lookup, scoped patch cleanup, basic components and storage. Not universal compatibility; unsupported Revenge Next ZIPs and native JARs are explicitly rejected.
- Existing package ID and signing. Original theme authors credited through their repositories and metadata.
